PROJECT DETAILS

Kira-Kira English

キッズ向けオンライン英会話教室

子ども向けオンライン英会話教室を想定したサービス紹介サイトです。提供されたデザインカンプをもとに、細かな余白や配置まで確認しながらコーディングしました。

制作区分
スクール最終課題
制作期間
21日間
制作範囲
デザインカンプをもとにしたコーディング
使用技術
HTML / CSS / JavaScript / jQuery / Slick

実装内容

  • サービス紹介ページのコーディング
  • PC・スマートフォンに対応したレスポンシブレイアウト
  • Slickを使用した画像カルーセル
  • タブ切り替えやアコーディオンメニュー
  • スクロールに連動したアニメーション演出

工夫した点・苦労した点

  • デザインカンプに設定された細かなmargin・paddingを読み取り、パーフェクトピクセルを意識して位置や余白を調整しました。
  • 3つの特色を紹介するエリアでは、左右から中央へ画像が移動するアニメーションを実装しました。
  • よくある質問のアコーディオンメニューでは、開閉状態に応じて三角形のアイコンが上下反転する動きを実装しました。
  • 見た目の再現だけでなく、アニメーションや開閉操作が自然に動作するよう調整しました。

実装状況について

本作品はスクールの最終課題として制作したデモサイトです。体験申し込みなどのリンクは表示用で、実際の予約・送信機能は実装していません。
