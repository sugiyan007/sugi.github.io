PROJECT DETAILS

Kirameki Design

コーポレートサイト

クリエイティブ企業を想定したコーポレートサイトです。企業紹介、事業内容、制作実績、ニュース、アクセスなどの情報を掲載するサイトを、提供されたデザインカンプをもとにコーディングしました。

制作区分
スクール課題
制作期間
18日間
制作範囲
デザインカンプをもとにしたコーディング
使用技術
HTML / CSS / JavaScript / jQuery

実装内容

  • トップページおよびアクセスページのコーディング
  • PC・スマートフォンに対応したレスポンシブレイアウト
  • jQueryを使用したタブ切り替え機能
  • ページ内のインタラクション実装

工夫した点・取り組んだこと

タブ切り替えでは「デザイン」「映像」「その他」のカテゴリーを切り替える機能を実装しました。デザインカンプの余白や配置を確認しながら、各画面幅でレイアウトが崩れないよう調整しました。

実装状況について

本作品は学習課題として制作したデモサイトです。アクセスページなど一部のページ遷移には対応していますが、一部のリンクは「#」を設定した表示用で、遷移先やお問い合わせ送信機能は実装していません。
